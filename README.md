# 릴스 스튜디오 (Reels Studio)

캡컷(CapCut) 없이 브라우저에서 바로 쓰는 **9:16 세로 릴스·클립 편집기**.
사진·영상·음성은 **서버로 전송되지 않고** 이 브라우저(메모리 · IndexedDB) 안에서만 처리됩니다.

**바로 열기 →** https://hotdeal-today.github.io/reels-editor/

## 주요 기능

### 1. 컷 편집
- 사진(JPG·PNG·WEBP)·영상(MP4·MOV·WEBM) 여러 개 불러오기, 드래그&드롭 지원
- 클립 순서 이동(드래그·↑↓), 교체, 복제, 삭제
- 영상 **시작 지점·표시 길이** 0.1초 조절(끝 지점 자동 계산), 재생 속도 0.5x~2.0x, 원본 오디오 볼륨·음소거
- **✂️ 목표 총 길이 자동 컷 맞추기** — `15초` / `18초` / `20초` 또는 직접 입력 후 `⚡ 자동 컷 맞추기`
  - 영상은 앞~중간(35%) 지점부터, 사진은 고르게 배분해 전체 길이를 목표 초수에 딱 맞춥니다(짧은 영상은 자기 길이만큼만 쓰고 남는 시간은 다른 클립에 재분배)
  - 마음에 안 들면 클립마다 **시작 지점·표시 길이** 슬라이더로 직접 조절
- 사진 표시 길이 + 모션(줌인·줌아웃·좌우 패닝), 컷/페이드 전환
- **◆ 키프레임 모션** — 클립마다 `◆ 시작 화면`→`◆ 끝 화면` 카메라 이동
  - `◆ 키프레임 모션 켜기` + 원클릭 프리셋 6종: `← 왼쪽→오른쪽 훑기` · `→ 오른쪽→왼쪽 훑기` · `↓ 위→아래` · `↑ 아래→위` · `🔍 천천히 확대` · `🔎 천천히 축소`
  - `◆ 시작 화면` / `◆ 끝 화면`을 골라 **확대·가로 X·세로 Y** 슬라이더로 직접 설정, `부드럽게`(이징) 켜고 끄기
  - `시작 보기` / `끝 보기` / `모든 클립에` / `초기화`
  - 켜져 있는 동안은 위 모션 효과·확대·위치 값 대신 키프레임이 쓰입니다(미리보기·MP4·캐러셀 모두 동일)
- 꽉 채우기·전체 맞춤, 확대·위치 조절, 밝기·대비·채도

### 2. 제목 · 배지 · 자막
- **한글 웹폰트 16종 · 영문 폰트 8종**을 Google Fonts로 불러와 제목·배지·자막에 각각 지정
  - 한글: 노토 산스 · 나눔고딕 · 고운돋움 · 고운바탕 · 주아(Jua) · 동글(Dongle) · 감자꽃(Gamja Flower) · 개구(Gaegu) · 싱글데이(Single Day) · 하이멜로디(Hi Melody) · 나눔손글씨 펜/붓 · 푸어스토리 · 검은고딕 · 도현 · 베이글팻원
  - 영문 전용: Pacifico · Dancing Script · Caveat · Fredoka · Bubblegum Sans · Lobster · Playfair Display · Montserrat
  - 폰트 선택지 아래에 **그 글꼴로 쓴 미리보기 줄**이 함께 보입니다. 폰트는 고른 것만 받아 와서 첫 화면이 가볍습니다
- `+ 내 폰트 추가` — TTF·OTF·WOFF2를 올리면 바로 적용되고 브라우저에 저장
- 제목/배지/자막 폰트 개별 지정 + 한 번에 통일
- 디자인 프리셋 7종(깔끔 화이트·네온 옐로우·자막 검정 박스·민트 포인트·핑크 배지·레퍼런스 화이트·레퍼런스 시안 발광)
- 크기·색·테두리·그림자·배경 박스/알약·둥글기·여백 세부 조절
- 미리보기에서 **글자를 직접 끌어** 위치 이동. **`전체 자막 위치 같이 움직이기`(기본 ON)** 이라 하나를 옮기면 모든 구간 자막이 같은 X·Y로 일렬 정렬됩니다. `현재 위치를 전체 자막에 적용` 버튼으로 한 번에 맞출 수도 있습니다
- 자막은 **Enter로 두 줄·여러 줄** 입력(미리보기·MP4 모두 입력한 줄바꿈 그대로 그립니다)
- 구간을 나눠 시간대별 제목·배지·자막 변경
- **▦ 자막 가림** — 영상·사진에 이미 박혀 있는 외국 자막을 크롭 없이 가립니다
  - 기본값은 **글자 줄만 좁게(너비 68% · 높이 9% · 가로 50% · 세로 78%)** 잡고 **희뿌연 블러 11px**만 입혀 경계가 티 나지 않게 가립니다
  - **미리보기 캔버스에서 블러 박스를 마우스·손가락으로 직접 끌어** 가로·세로 위치를 옮길 수 있습니다(끄는 동안 점선 박스 + 가로·세로 % 안내, 내보내기에는 안 들어감)
  - 슬라이더: **가로 위치(중심 %)**·세로 위치(중심 %)·높이 %·너비 %·**희뿌연 블러**(px)·**모자이크 조각**(px, 0=끔)
  - 가림 영역 상하좌우 가장자리는 원본 화면과 부드럽게 섞여(페더 마스크) 사각 테두리가 보이지 않습니다
  - `전체 기본값` / `N번 클립만` — 클립마다 따로 설정하거나 모든 클립에 한 번에 적용
  - `가이드`를 켜면 미리보기에 점선 영역이 보입니다
  - 미리보기·MP4 내보내기·캐러셀 카드 모두 같은 영역에 적용되고, 그 위에 한글 자막이 올라갑니다

### 3. 음성 · BGM · 효과음
- Web Audio로 직접 합성한 내장 효과음 8종 (뽕·쉭·딩동·짠·타닥·삐·두둥·찰칵) — 외부 파일 없이 항상 동작
- `+ 내 효과음 추가` (mp3·wav·m4a·aac)
- 마이크 녹음 / 음성 파일 업로드, 시작 시간·볼륨
- BGM 업로드, 볼륨, 페이드 인/아웃
- 효과음 블록을 타임라인에서 0.05초 단위로 드래그, 볼륨 0~150%

### 4. 내보내기
- 1080×1920 / 720×1280, 30fps
- **WebCodecs + mp4-muxer**로 실제 MP4 인코딩 (빠름, 프레임 정확)
- 미지원 브라우저는 **MediaRecorder 실시간 녹화**로 자동 폴백
- 진행률 표시, 완료 즉시 다운로드
- 현재 프레임을 `thumbnail.jpg`로 저장
- **🖼️ 캐러셀 카드 (만들고 · 고치고 · 저장)** — `4:5 피드(1080×1350)` / `9:16(1080×1920)`, **장수 `4`·`5`·`6`·`8`·`10`장 · 직접 입력(2~40) · `전체`(불러온 사진 수)**
  - `전체`는 지금 있는 사진(블로그에서 불러온 사진 포함)을 모두 카드로 만듭니다. `＋`로 카드를 더 붙이거나 `🗑`로 줄일 수도 있습니다
  - **`⚡ 지금 컷으로 카드 만들기`** — 타임라인 전체에서 서로 다른 장면을 골라 대표 카드 + 장면 카드를 만듭니다(영상 1개만 있어도 4~6장이 모두 다른 장면)
  - **`📥 블로그 사진으로`** — AI 세팅 탭에서 불러온 블로그 사진으로 대표 카드 + 장면 카드를 만듭니다. 사진이 모자라면 만든 장수와 이유를 알려 줍니다
  - **카드를 누르면 카드 편집기가 열립니다**
    - 제목 / 부제 문구 직접 수정
    - 위치: `상단`·`중앙`·`하단` 프리셋 + 세로 위치 슬라이더(6~94%)
    - 글자 크기(제목 28~120 · 부제 16~80) 슬라이더
    - 글자 색 · 강조 바(배경 박스) 색 — 컬러 피커 + 빠른 스와치 8개, 배경 켜기/끄기
    - 사진 교체(프로젝트 사진 선택 또는 파일 올리기) · 확대(100~250%) · 좌우/위아래 위치
    - `＋` 카드 추가 · `🗑` 카드 삭제 · `←`/`→` 카드 이동
  - 고친 내용은 **카드 미리보기와 저장 파일에 바로 반영**되고 프로젝트에 저장돼 새로고침해도 그대로입니다
  - `📥 JPG 모두 저장` / **`🗜 ZIP으로 저장`** (압축 없이 묶는 방식 — 라이브러리 없이 동작)
  - 카드별 저장 버튼으로 한 장만 받을 수도 있습니다

### 5. ✨ AI 자동 세팅 (탭5)
키 없이도 바로 쓰는 기능과, 무료 Gemini 키로 쓰는 기능을 함께 넣었습니다.

- **📥 블로그 URL 하나로 끝내기** (이 탭 맨 위)
  - 네이버 블로그 주소(`https://blog.naver.com/rkwhr83/224491139890`)를 넣고 `불러오기`
  - **글 제목 · 본문 · 사진**을 한 번에 가져옵니다. 사진은 본문 순서대로 뽑고, 사진 바로 앞 문단을 그 사진의 설명으로 붙입니다
  - **사진 수 기본값은 `전체`** — 글에 사진이 8장이든 14장이든 자르지 않고 전부 불러오고, 릴스 컷·캐러셀 카드에도 전부 들어갑니다(사진 수에서 4·6·8·10·12장으로 줄일 수 있음). 내려받기 실패는 한 번 더 재시도하고, 그래도 빠진 사진이 있으면 상태 줄에 개수를 알려 줍니다
  - 4번 내보내기 탭의 `블로그 사진 불러오기`도 같은 방식으로 **전부** 가져오고, 카드가 없으면 사진 전체로 카드를 만듭니다
  - 경로를 차례로 시도합니다: `r.jina.ai`(CORS 허용 텍스트 추출 서비스, HTML/본문) → `corsproxy.io` → `allorigins` → `codetabs` → 직접 요청. 실패한 경로는 건너뛰고 되는 경로로 이어 갑니다
  - 사진은 **프록시(`images.weserv.nl`)로 받아 Blob → ObjectURL**로 넣기 때문에 캔버스에 그려도 `tainted canvas`(CORS) 오류가 없고, MP4·JPG 내보내기가 그대로 됩니다
  - 너무 작은 배너·공지 이미지, 프로필·스티커·링크 미리보기 이미지는 걸러냅니다
  - 불러온 자료로 **`⚡ 릴스 만들기`** · **`🖼 캐러셀`** · **`⚡ 둘 다 만들기`** (릴스 + 캐러셀 + 5채널 캡션)
    - 릴스: 사진을 컷으로 배치하고(사진 길이·총 길이 선택), **제목·배지·자막·나레이션**을 만듭니다. Gemini 키가 있으면 사진과 본문을 읽어 자막을 다듬고, 없으면 본문의 소제목·핵심 문장에서 자막을 뽑습니다

#### 사진 ↔ 자막 1:1 매칭 + 인스타 자막 문법 (v10, 2026-11-28)
"사진이랑 자막이 안 맞는다"는 지적을 고친 부분입니다. 근거는 `work/reels_caption_benchmark_20261128/report.md`(인스타 릴스 자막 5원칙).
- **사진마다 제 문맥을 들고 다닙니다** — 블로그를 불러올 때 사진 URL만 뽑지 않고, 그 사진의 **소제목 · 바로 앞 문단 3줄 · 바로 뒤 문단 4줄 · alt**를 함께 저장합니다(`js/blog.js` → `js/blogflow.js`). 문단이 줄바꿈으로 끊겨 있어도 다시 붙여 문장으로 되살립니다
- **컷 1장 = 자막 1줄** — `⚡ 릴스 만들기`·`원클릭`·`붙여넣기` 모두 사진 순서대로 1:1로 붙습니다. 컷 수와 자막 수가 어긋나지 않고, 시간도 클립 시간 그대로 씁니다(`cut` 번호로 잠금)
- **첫 0~3초는 후킹 한 방** — 숙소·여행 글은 `지역 반전 / 거리+결과 / 조건 반전 / 희소·경고` 중 본문 사실로 하나. 예: `서울에서 한 시간이면` + `방 안에 온천수가?`. 숙소명·가격 나열로 시작하지 않고, `총정리·가성비·끝판왕·필수템` 같은 평가어는 자동으로 걸러 다시 씁니다
- **2컷부터는 사진마다 그 사진의 포인트 한 줄** — 말끝을 억지로 연결어미로 바꾸지 않습니다(아래 v11). 4~14자·한 컷에 정보 하나만 남깁니다
- **마지막 2컷** — 예약·주의 팁 한 줄(예: `12월 주말은 벌써 빠지고 있어요`) + 저장 CTA(`연말 전에 미리 저장해두세요`)
- **정보 표 캡처·도입 배너·제휴 링크 썸네일은 릴스 컷에서 제외**합니다(캐러셀에는 그대로). 가격 표 이미지가 컷으로 들어가 "7만 원 / 60만 원" 나열이 되던 문제를 없앴습니다
- **AI 세팅 탭에 `컷별 사진 문맥 → 자막` 표**가 생겼습니다. 컷 번호·소제목·만들어진 자막을 한눈에 보고, 잘못 붙은 줄은 2번 탭에서 고치면 됩니다
- **Gemini·무료 챗봇 프롬프트**에도 `[컷 1: 소제목 / 앞 문맥 / 뒤 문맥]` 표를 그대로 넣고, `segments`를 사진 수만큼·`cut` 번호와 함께 달라고 요구합니다. 돌아온 답에 라벨·평가어·가격 나열이 있으면 사진 문맥 줄로 자동 교체하고 몇 곳을 고쳤는지 알려 줍니다

#### 자막 사람 말투 · 핵심 매력 교정 (v11, 2026-11-28)
"넓어서, 숙소라서, 있어서 — 이렇게 들어가면 안 되지 / 5세부터 참여할 수 있어서가 왜 중요해" 지적을 고친 부분입니다.
- **`~라서/~있어서` 기계적 변환 제거** (`js/reelscopy.js`) — 해요체(`방 안에 온천수가 나와요`)·짧은 명사구(`탕 옆에 바로 침대`, `통창 너머가 전부 바다`)·반문을 섞고, 같은 말투 어미가 2컷 연속 나오지 않게 검사합니다(짧은 명사구가 이어지는 건 허용 — 그게 사람 릴스 말투)

### 나레이션 (자막과 1:1) — 3번 음성·효과 탭
| 방식 | 영상(MP4)에 들어가나 | 키 |
|---|---|---|
| **Gemini TTS** (`gemini-2.5-flash-preview-tts`, PCM 24kHz → WAV 변환) | ✅ 들어갑니다 | 무료 Gemini 키 |
| 브라우저 `speechSynthesis` | ❌ 스피커 출력만 — **음성 파일이 없을 때 단독 미리듣기 전용** | 없음 |
| 마이크 녹음 (구간별, 자동 종료) | ✅ 들어갑니다 | 없음 |
| 외부 TTS 파일(클로바더빙·브루·타입캐스트) 구간별 삽입 | ✅ 들어갑니다 | 없음 |

나레이션은 **3번 음성·효과 탭 한 곳**에서 다룹니다 — 목소리 선택 · 속도 · 자막과 연동된 초별 목록 · `전체 자막 TTS 만들기` · 구간별 🔊 듣기 / ✨ TTS / 🎙 녹음 / 📁 파일. 5번 AI 세팅 탭에는 현재 맞는지 상태 요약만 남겼습니다.

**대본은 자막 하나뿐입니다.** 자막 글자(제목·배지·자막)를 2번이나 3번 목록에서 고치면 그 구간 나레이션의 대본이 **즉시 같은 글자로** 바뀌고, 시작 시각도 자막 시작 초를 따라갑니다. 이미 만든 오디오가 옛 대본과 다르면 `대본 바뀜` 배지(타임라인에는 ✎)로 표시하고, `자막 기준으로 나레이션 다시 맞추기` 한 번이면 자막 그대로 다시 만듭니다.

**트랙은 항상 '자막 1개 = 음성 1개'입니다.** 프로젝트를 열 때 옛 구간에 남은 음성·한 구간에 겹친 음성·구간에 안 묶인 음성을 자동으로 정리합니다. `전체 자막 TTS 만들기`는 트랙을 전부 비운 뒤 현재 자막 기준으로 **딱 1세트**를 다시 만들고, 목소리는 고른 한 가지(예: Aoede)로 전 구간을 통일합니다.

**속도 조절** — 0.8x~1.5x(기본 1.0x). 미리듣기·타임라인 재생·MP4 내보내기가 같은 값을 쓰고, 음성이 자막보다 길면 이 속도에 자동 압축(최대 1.35배)을 곱해 겹침 0을 지킵니다.

**두 목소리가 겹치지 않습니다.** 재생을 시작하면 브라우저 음성(`speechSynthesis.cancel()`), 구간 음성 '듣기' 오디오, 효과음 미리듣기를 모두 먼저 멈춥니다. 전체 길이 나레이션 파일과 자막별 나레이션을 같이 켜면 경고와 함께 `전체 파일 끄기`를 한 번에 눌러 정리할 수 있습니다(자막별 나레이션을 만들면 자동으로 꺼집니다).

**겹침 0 자동 보정**
자막 구간이 2초인데 Gemini TTS가 2.9초 음성을 만들면, 그대로 두면 앞 음성이 끝나기 전에 다음 음성이 시작돼 목소리가 2~3개 겹쳐 들립니다. 그래서 배치 계산(`js/voicelayout.js`)이
① 앞 음성이 **끝난 뒤에만** 다음 음성을 시작하고(최소 여백 0.04초),
② 다음 자막이 뜨기 전에 끝나도록 필요한 만큼만 **최대 1.35배속**하며,
③ 그래도 넘치면 다음 자막이 뜬 뒤 **0.3초까지는 문장을 끝까지** 들려주고, 그 뒤에 남는 꼬리만 끊습니다.
TTS 앞뒤 무음도 재서(`lead`/`tail`) 배속 계산에서 빼므로, 실제로는 배속 없이 들어가는 경우가 많습니다(예: 2.9초 음성 → 무음 빼면 2.6초 → 2.0초 자막에 1.27배속, 잘림 0).
이 계산은 미리듣기와 MP4 내보내기가 **같은 함수(`buildMix`)에서 한 번에** 쓰므로 두 결과가 항상 같습니다.
콘솔에서 `__reelsVoicePlan()` 을 치면 지금 배치의 겹침 여부를 바로 확인할 수 있습니다.

## 앱으로 설치 (PWA)
모바일 크롬에서 주소창 메뉴 → **홈 화면에 추가 / 앱 설치**가 됩니다.
`manifest.json`(이름·아이콘 192/512·maskable·standalone)과 서비스워커(`sw.js`)가 있어 크롬 설치 조건을 만족하고, 한 번 열면 **인터넷이 없어도** 열립니다(파일은 항상 네트워크를 먼저 확인해 최신 버전을 받습니다).

## 작업 자동 저장
프로젝트 상태·미디어·커스텀 폰트·커스텀 효과음은 IndexedDB(`reels-studio`)에 저장됩니다.
같은 브라우저에서 다시 열면 이어서 편집할 수 있습니다.
