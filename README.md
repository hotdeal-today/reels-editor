# 릴스 스튜디오 (Reels Studio)

캡컷(CapCut) 없이 브라우저에서 바로 쓰는 **9:16 세로 릴스·클립 편집기**.
사진·영상·음성은 **서버로 전송되지 않고** 이 브라우저(메모리 · IndexedDB) 안에서만 처리됩니다.

**바로 열기 →** https://hotdeal-today.github.io/reels-editor/

## 주요 기능

### 1. 컷 편집
- 사진(JPG·PNG·WEBP)·영상(MP4·MOV·WEBM) 여러 개 불러오기, 드래그&드롭 지원
- 클립 순서 이동(드래그·↑↓), 교체, 복제, 삭제
- 영상 구간 in/out 0.1초 조절, 재생 속도 0.5x~2.0x, 원본 오디오 볼륨·음소거
- 사진 표시 길이 + 모션(줌인·줌아웃·좌우 패닝), 컷/페이드 전환
- 꽉 채우기·전체 맞춤, 확대·위치 조절, 밝기·대비·채도

### 2. 제목 · 배지 · 자막
- 한글 웹폰트 7종 내장(노토 산스, 검은고딕, 도현, 주아, 나눔고딕, 나눔손글씨, 고운바탕)
- `+ 내 폰트 추가` — TTF·OTF·WOFF2를 올리면 바로 적용되고 브라우저에 저장
- 제목/배지/자막 폰트 개별 지정 + 한 번에 통일
- 디자인 프리셋 5종(깔끔 화이트·네온 옐로우·자막 검정 박스·민트 포인트·핑크 배지)
- 크기·색·테두리·그림자·배경 박스/알약·둥글기·여백 세부 조절
- 미리보기에서 **글자를 직접 끌어** 위치 이동, `이 위치를 모든 구간에 적용`
- 구간을 나눠 시간대별 제목·배지·자막 변경
- **▦ 자막 모자이크** — 영상·사진에 이미 박혀 있는 외국 자막을 크롭 없이 가립니다
  - 세로 위치(중심 %)·높이 %·너비 %·모자이크 크기(px)·살짝 블러를 슬라이더로 조절
  - `전체 기본값` / `N번 클립만` — 클립마다 따로 설정하거나 모든 클립에 한 번에 적용
  - `가이드`를 켜면 미리보기에 점선 영역이 보입니다
  - 미리보기·MP4 내보내기·캐러셀 카드 모두 같은 영역에 적용되고, 그 위에 한글 자막이 올라갑니다

### 3. 음성 · BGM · 효과음
- Web Audio로 직접 합성한 내장 효과음 8종 (뽕·쉭·딩동·짠·타닥·삐·두둥·찰칵) — 외부 파일 없이 항상 동작
- `+ 내 효과음 추가` (mp3·wav·m4a·aac)
- 마이크 녹음 / 음성 파일 업로드, 시작 시간·볼륨
- BGM 업로드, 볼륨, 페이드 인/아웃
- 효과음 블록을 타임라인에서 0.05초 단위로 드래그, 볼륨 0~150%

### 4. 내보내기
- 1080×1920 / 720×1280, 30fps
- **WebCodecs + mp4-muxer**로 실제 MP4 인코딩 (빠름, 프레임 정확)
- 미지원 브라우저는 **MediaRecorder 실시간 녹화**로 자동 폴백
- 진행률 표시, 완료 즉시 다운로드
- 현재 프레임을 `thumbnail.jpg`로 저장
- **🖼️ 캐러셀 이미지 세트** — `4:5 피드(1080×1350)` / `9:16(1080×1920)` 선택
  - 1번 카드 = 대표 썸네일 + 제목 + 배지, 이후 카드 = 클립별 프레임 + 그 구간 자막
  - 화면에 미리보기를 띄우고 카드별 저장 / `📥 카드 모두 저장`(순차 다운로드)
  - 글자가 잘 읽히도록 아래쪽에 그라데이션을 깔고, 모자이크 영역은 카드 비율에 맞춰 같이 이동

### 5. ✨ AI 자동 세팅 (탭5)
키 없이도 바로 쓰는 두 가지와, 무료 Gemini 키로 쓰는 두 가지를 함께 넣었습니다.

- **📝 블로그 글 → 5채널 캡션** (클립·인스타그램·유튜브 쇼츠·페이스북·스레드)
  - 블로그 URL `가져오기 시도` — 네이버는 CORS로 막히면 텍스트 추출 서비스를 거쳐 시도하고, 실패하면 이유를 알려 주고 본문 붙여넣기로 바로 이어집니다
  - 본문을 붙여넣고 `✨ 5채널 캡션 만들기`(무료 Gemini 키) 또는 `📋 프롬프트 복사 → 📥 결과 붙여넣기`(키 없이 무료 챗봇)
  - 채널마다 다른 말투·구성: 네이버 클립은 `#오늘클립챌린지 #클립크리에이터` + 연관 키워드 3개(해시태그 5개), 인스타는 프로필 링크 유도 + 해시태그, 유튜브는 제목/설명, 페이스북은 공감·안내, 스레드는 반말·줄바꿈·링크 없는 단독 본문
  - 카드마다 `📋 복사`, 만든 캡션은 브라우저에 저장(새로고침해도 유지)

- **⚡ 원클릭 자동 배치** (키 필요 없음)
  - 사진 표시 길이 조정, 영상은 최대 4.2초로 컷
  - 모션(줌인/줌아웃/패닝) 자동 순환, 컷마다 페이드 전환
  - 디자인 세트 3종(네온·깔끔·블랙박스) 자동 적용
  - 효과음 자동 배치 — 시작 `짠`, 컷마다 `쉭`, 마지막 후킹 구간 `뽕`
  - 마지막 1.6~2.8초를 후킹 구간으로 떼어 `자세한 내용은 본문에서 확인하세요👇` 배치
- **📋 무료 ChatGPT·Gemini 채팅용 프롬프트 + 📥 결과 붙여넣기**
  - 프롬프트 복사 → 무료 채팅에 사진과 함께 붙여넣기 → 받은 JSON을 그대로 붙여넣으면 제목·배지·구간 자막·효과음이 한 번에 적용
  - 코드블록(\`\`\`json), 한글 키(제목·배지·자막·구간), 뒤따르는 쉼표까지 느슨하게 파싱
- **✨ Gemini API 자동 세팅** (Google AI Studio 무료 키)
  - `aistudio.google.com/apikey`에서 받은 무료 키를 브라우저(localStorage)에만 저장(서버 전송 없음)
  - 현재 사진·영상에서 대표 프레임을 뽑아(영상은 캔버스로 프레임 추출) `gemini-2.5-flash` 등에 함께 전송
  - 제목·배지·구간별 자막·마지막 후킹 멘트·효과음(종류+타이밍) JSON을 받아 타임라인에 적용
  - `연결 확인` 버튼이 키로 실제 사용 가능한 모델 목록을 조회해 최신 모델을 자동 선택 (모델명이 바뀌어도 동작)
- **💾 프로젝트 저장 / 불러오기 (.json)** — 미디어를 뺀 템플릿·세팅 공유용

### 한국어 TTS (자막 읽어주기) — 실제 동작 범위
| 방식 | 영상(MP4)에 들어가나 | 키 |
|---|---|---|
| **Gemini TTS** (`gemini-2.5-flash-preview-tts`, PCM 24kHz → WAV 변환) | ✅ 들어갑니다 | 무료 Gemini 키 |
| 브라우저 `speechSynthesis` | ❌ 스피커 출력만 (구간 타이밍 미리듣기용) | 없음 |
| 마이크 녹음 (구간별, 자동 종료) | ✅ 들어갑니다 | 없음 |
| 외부 TTS 파일(클로바더빙·브루·타입캐스트) 구간별 삽입 | ✅ 들어갑니다 | 없음 |

브라우저 기본 음성은 `MediaStreamDestination`으로 잡을 수 없어 MP4에 섞을 수 없습니다. 그래서 Gemini 키가 있으면 실제 오디오 파일을 만들어 믹싱하고, 키가 없으면 녹음·외부 파일로 같은 결과를 낼 수 있게 했습니다.
구간 음성은 타임라인 `나레이션` 트랙에 표시되고 미리보기·내보내기에 함께 섞입니다.

## 작업 자동 저장
프로젝트 상태·미디어·커스텀 폰트·커스텀 효과음은 IndexedDB(`reels-studio`)에 저장됩니다.
같은 브라우저에서 다시 열면 이어서 편집할 수 있습니다.

## 기술
- 빌드 도구 없는 정적 사이트 (ES Modules)
- `mp4-muxer` 로컬 번들, WebCodecs `VideoEncoder`/`AudioEncoder`
- 캔버스 2D 합성(1080×1920 좌표계), OfflineAudioContext 믹스다운

## 개인정보
업로드한 파일은 어떤 서버로도 전송되지 않습니다. 모든 처리·합성·인코딩은 클라이언트 사이드에서 이루어집니다.

예외는 두 가지뿐이고, 둘 다 사용자가 직접 켜야 동작합니다.
- **Gemini 자동 세팅·TTS·5채널 캡션**: 프레임 이미지(최대 8장)·자막 문장·블로그 본문이 Google Gemini API로 전송됩니다. 키는 브라우저에만 저장됩니다.
- **블로그 URL 가져오기**: 주소만 무료 텍스트 추출 서비스(r.jina.ai) 또는 공개 프록시로 전달해 본문을 읽어옵니다. 붙여넣기로 쓰면 이 전송도 일어나지 않습니다.
- 프롬프트 복사는 클립보드에만 넣고 아무 데도 보내지 않습니다.
