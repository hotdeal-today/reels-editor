# 릴스 스튜디오 (Reels Studio)

캡컷(CapCut) 없이 브라우저에서 바로 쓰는 **9:16 세로 릴스·클립 편집기**.
사진·영상·음성은 **서버로 전송되지 않고** 이 브라우저(메모리 · IndexedDB) 안에서만 처리됩니다.

**바로 열기 →** https://hotdeal-today.github.io/reels-editor/

## 주요 기능

### 1. 컷 편집
- 사진(JPG·PNG·WEBP)·영상(MP4·MOV·WEBM) 여러 개 불러오기, 드래그&드롭 지원
- 클립 순서 이동(드래그·↑↓), 교체, 복제, 삭제
- 영상 **시작 지점·표시 길이** 0.1초 조절(끝 지점 자동 계산), 재생 속도 0.5x~2.0x, 원본 오디오 볼륨·음소거
- **✂️ 목표 총 길이 자동 컷 맞추기** — `15초` / `18초` / `20초` 또는 직접 입력 후 `⚡ 자동 컷 맞추기`
  - 영상은 앞~중간(35%) 지점부터, 사진은 고르게 배분해 전체 길이를 목표 초수에 딱 맞춥니다(짧은 영상은 자기 길이만큼만 쓰고 남는 시간은 다른 클립에 재분배)
  - 마음에 안 들면 클립마다 **시작 지점·표시 길이** 슬라이더로 직접 조절
- 사진 표시 길이 + 모션(줌인·줌아웃·좌우 패닝), 컷/페이드 전환
- **◆ 키프레임 모션** — 클립마다 `◆ 시작 화면`→`◆ 끝 화면` 카메라 이동
  - `◆ 키프레임 모션 켜기` + 원클릭 프리셋 6종: `← 왼쪽→오른쪽 훑기` · `→ 오른쪽→왼쪽 훑기` · `↓ 위→아래` · `↑ 아래→위` · `🔍 천천히 확대` · `🔎 천천히 축소`
  - `◆ 시작 화면` / `◆ 끝 화면`을 골라 **확대·가로 X·세로 Y** 슬라이더로 직접 설정, `부드럽게`(이징) 켜고 끄기
  - `시작 보기` / `끝 보기` / `모든 클립에` / `초기화`
  - 켜져 있는 동안은 위 모션 효과·확대·위치 값 대신 키프레임이 쓰입니다(미리보기·MP4·캐러셀 모두 동일)
- 꽉 채우기·전체 맞춤, 확대·위치 조절, 밝기·대비·채도

### 2. 제목 · 배지 · 자막
- **한글 웹폰트 16종 · 영문 폰트 8종**을 Google Fonts로 불러와 제목·배지·자막에 각각 지정
  - 한글: 노토 산스 · 나눔고딕 · 고운돋움 · 고운바탕 · 주아(Jua) · 동글(Dongle) · 감자꽃(Gamja Flower) · 개구(Gaegu) · 싱글데이(Single Day) · 하이멜로디(Hi Melody) · 나눔손글씨 펜/붓 · 푸어스토리 · 검은고딕 · 도현 · 베이글팻원
  - 영문 전용: Pacifico · Dancing Script · Caveat · Fredoka · Bubblegum Sans · Lobster · Playfair Display · Montserrat
  - 폰트 선택지 아래에 **그 글꼴로 쓴 미리보기 줄**이 함께 보입니다. 폰트는 고른 것만 받아 와서 첫 화면이 가볍습니다
- `+ 내 폰트 추가` — TTF·OTF·WOFF2를 올리면 바로 적용되고 브라우저에 저장
- 제목/배지/자막 폰트 개별 지정 + 한 번에 통일
- 디자인 프리셋 7종(깔끔 화이트·네온 옐로우·자막 검정 박스·민트 포인트·핑크 배지·레퍼런스 화이트·레퍼런스 시안 발광)
- 크기·색·테두리·그림자·배경 박스/알약·둥글기·여백 세부 조절
- 미리보기에서 **글자를 직접 끌어** 위치 이동, `이 위치를 모든 구간에 적용`
- 구간을 나눠 시간대별 제목·배지·자막 변경
- **▦ 자막 가림** — 영상·사진에 이미 박혀 있는 외국 자막을 크롭 없이 가립니다
  - 기본값은 **글자 줄만 좁게(너비 68% · 높이 9% · 가로 50% · 세로 78%)** 잡고 **희뿌연 블러 11px**만 입혀 경계가 티 나지 않게 가립니다
  - **미리보기 캔버스에서 블러 박스를 마우스·손가락으로 직접 끌어** 가로·세로 위치를 옮길 수 있습니다(끄는 동안 점선 박스 + 가로·세로 % 안내, 내보내기에는 안 들어감)
  - 슬라이더: **가로 위치(중심 %)**·세로 위치(중심 %)·높이 %·너비 %·**희뿌연 블러**(px)·**모자이크 조각**(px, 0=끔)
  - 가림 영역 상하좌우 가장자리는 원본 화면과 부드럽게 섞여(페더 마스크) 사각 테두리가 보이지 않습니다
  - `전체 기본값` / `N번 클립만` — 클립마다 따로 설정하거나 모든 클립에 한 번에 적용
  - `가이드`를 켜면 미리보기에 점선 영역이 보입니다
  - 미리보기·MP4 내보내기·캐러셀 카드 모두 같은 영역에 적용되고, 그 위에 한글 자막이 올라갑니다

### 3. 음성 · BGM · 효과음
- Web Audio로 직접 합성한 내장 효과음 8종 (뽕·쉭·딩동·짠·타닥·삐·두둥·찰칵) — 외부 파일 없이 항상 동작
- `+ 내 효과음 추가` (mp3·wav·m4a·aac)
- 마이크 녹음 / 음성 파일 업로드, 시작 시간·볼륨
- BGM 업로드, 볼륨, 페이드 인/아웃
- 효과음 블록을 타임라인에서 0.05초 단위로 드래그, 볼륨 0~150%

### 4. 내보내기
- 1080×1920 / 720×1280, 30fps
- **WebCodecs + mp4-muxer**로 실제 MP4 인코딩 (빠름, 프레임 정확)
- 미지원 브라우저는 **MediaRecorder 실시간 녹화**로 자동 폴백
- 진행률 표시, 완료 즉시 다운로드
- 현재 프레임을 `thumbnail.jpg`로 저장
- **🖼️ 캐러셀 이미지 세트** — `4:5 피드(1080×1350)` / `9:16(1080×1920)` 선택, **장수 `4장`·`5장`·`6장`** 선택
  - 1번 카드 = 대표 썸네일 + 제목 + 배지
  - 2~N번 카드 = 타임라인 전체(0~총 길이)를 고르게 나눠 **서로 다른 시점**의 프레임 추출(자막이 있는 구간 우선) — **영상 1개만 있어도 4~6장이 모두 다른 장면**
  - 사진이 모자라면 같은 사진을 두 번 넣지 않고 가능한 장수만 만들며 안내 문구를 보여 줍니다
  - **카드마다 문구 입력 칸** — 1번은 제목, 2~N번은 그 카드 자막을 직접 고치면 그 카드만 즉시 다시 그려지고, 저장 파일에도 수정한 문구가 들어갑니다
  - 카드별 **시점(초) 미세조정** — 숫자를 바꾸면 그 장면만 다시 찍습니다
  - 화면에 미리보기를 띄우고 카드별 저장 / `📥 카드 모두 저장`(순차 다운로드)
  - 글자가 잘 읽히도록 아래쪽에 그라데이션을 깔고, 가림 영역은 카드 비율에 맞춰 같이 이동

### 5. ✨ AI 자동 세팅 (탭5)
키 없이도 바로 쓰는 두 가지와, 무료 Gemini 키로 쓰는 두 가지를 함께 넣었습니다.

- **📝 블로그 글 → 5채널 캡션** (클립·인스타그램·유튜브 쇼츠·페이스북·스레드)
  - 블로그 URL `가져오기 시도` — 네이버는 CORS로 막히면 텍스트 추출 서비스를 거쳐 시도하고, 실패하면 이유를 알려 주고 본문 붙여넣기로 바로 이어집니다
  - 본문을 붙여넣고 `✨ 5채널 캡션 만들기`(무료 Gemini 키) 또는 `📋 프롬프트 복사 → 📥 결과 붙여넣기`(키 없이 무료 챗봇)
  - 채널마다 다른 말투·구성: 네이버 클립은 `#오늘클립챌린지 #클립크리에이터` + 연관 키워드 3개(해시태그 5개), 인스타는 프로필 링크 유도 + 해시태그, 유튜브는 제목/설명, 페이스북은 공감·안내, 스레드는 반말·줄바꿈·링크 없는 단독 본문
  - 카드마다 `📋 복사`, 만든 캡션은 브라우저에 저장(새로고침해도 유지)

- **⚡ 원클릭 자동 배치** (키 필요 없음) — Gemini 키가 저장돼 있으면 이 카드는 `✨ Gemini` 아래로 내려가고, Gemini 카드가 맨 위에 `추천`으로 강조됩니다
  - **레퍼런스 공식대로 자막을 채움** (2026-11-26 상위 릴스 2편 분석: `@home_tembbly` 22.5초·자막 22개, `@homterior_pick` 28.4초·자막 27개)
    - 구조: 문제 제기 → "~하지 마세요" 금지 명령 → 전환("근데 이건…") → 기능(동작→결과) → 정보(기종·가격) → CTA → 엔드카드 2줄
    - 한 자막 4~14자 · 1줄 · 해요체 구어체 · 숫자·스펙은 한 줄에 하나
  - **자막 호흡 선택**: `여유 (2~3초에 한 줄)` / `레퍼런스 (1.2~1.8초에 한 줄)` — 기본은 기존 기준(여유)
  - **카피 틀 편집** — 한 줄에 하나씩 쓰면 그 문장이 그대로 들어갑니다(`{t}`는 주제·프로젝트 이름). `기본 틀 넣기`로 공식 틀을 불러와 고칠 수 있습니다
  - **배치**: 1컷만 상단 후킹(제목·배지), 1컷 자막 58%, 2컷부터 하단 세이프존(74%), 마지막 컷은 가운데 2줄 엔드카드
  - 사진 표시 길이 조정, **영상은 넣은 길이 그대로**(예전처럼 4.2초로 잘라 버리지 않음)
  - 모션(줌인/줌아웃/패닝) 자동 순환, 컷마다 페이드 전환
  - 디자인 세트 4종(레퍼런스 화이트·네온·깔끔·블랙박스) 자동 적용
  - 효과음 자동 배치 — 시작 `짠`, 컷마다 `쉭`, 마지막 후킹 구간 `뽕`
  - **제목·배지가 비지 않습니다** — 프로젝트 이름이 `새 릴스`이거나 비어 있으면 `주제` 입력값, 그것도 없으면 `오늘의 추천 릴스` + `BEST`(팁·할인 뉘앙스면 `꿀팁`)가 반드시 들어갑니다
  - **나레이션도 함께 맞춥니다** — 배치 전에 옛 나레이션 트랙을 비우고, `🎙 나레이션까지 자동 생성`이 켜져 있으면 새 자막 **각각과 1:1(같은 글·같은 시작 초)** 로 Gemini TTS를 다시 만듭니다
- **📋 무료 ChatGPT·Gemini 채팅용 프롬프트 + 📥 결과 붙여넣기**
  - 프롬프트 복사 → 무료 채팅에 사진과 함께 붙여넣기 → 받은 JSON을 그대로 붙여넣으면 제목·배지·구간 자막·효과음이 한 번에 적용
  - 코드블록(\`\`\`json), 한글 키(제목·배지·자막·구간), 뒤따르는 쉼표까지 느슨하게 파싱
- **✨ Gemini API 자동 세팅** (Google AI Studio 무료 키) — 키를 저장하면 이 카드가 AI 탭 **맨 위로 올라와** `추천` 표시로 강조됩니다(키 없는 원클릭과 헷갈리지 않게)
  - `aistudio.google.com/apikey`에서 받은 무료 키를 브라우저(localStorage)에만 저장(서버 전송 없음)
  - 현재 사진·영상에서 프레임을 뽑아 `gemini-2.5-flash` 등에 함께 전송 — **영상 1개당 2~3프레임(시작·중간·끝)** 을 뽑고 `영상 2 (13.0초) 6.5초 지점`처럼 위치를 붙여 보냅니다
  - 제목·배지·구간별 자막·마지막 후킹 멘트·효과음(종류+타이밍) JSON을 받아 타임라인에 적용
  - AI가 자막을 적게 줘도 전체 길이 기준 2~3초 박자로 자동 분할해 0초~끝까지 빈틈없이 채웁니다
  - `연결 확인` 버튼이 키로 실제 사용 가능한 모델 목록을 조회해 최신 모델을 자동 선택 (모델명이 바뀌어도 동작)
- **💾 프로젝트 저장 / 불러오기 (.json)** — 미디어를 뺀 템플릿·세팅 공유용

### 한국어 TTS (자막 읽어주기) — 실제 동작 범위
| 방식 | 영상(MP4)에 들어가나 | 키 |
|---|---|---|
| **Gemini TTS** (`gemini-2.5-flash-preview-tts`, PCM 24kHz → WAV 변환) | ✅ 들어갑니다 | 무료 Gemini 키 |
| 브라우저 `speechSynthesis` | ❌ 스피커 출력만 (구간 타이밍 미리듣기용) | 없음 |
| 마이크 녹음 (구간별, 자동 종료) | ✅ 들어갑니다 | 없음 |
| 외부 TTS 파일(클로바더빙·브루·타입캐스트) 구간별 삽입 | ✅ 들어갑니다 | 없음 |

브라우저 기본 음성은 `MediaStreamDestination`으로 잡을 수 없어 MP4에 섞을 수 없습니다. 그래서 Gemini 키가 있으면 실제 오디오 파일을 만들어 믹싱하고, 키가 없으면 녹음·외부 파일로 같은 결과를 낼 수 있게 했습니다.
구간 음성은 타임라인 `나레이션` 트랙에 표시되고 미리보기·내보내기에 함께 섞입니다.

**자막과 나레이션은 같이 움직입니다.** `⚡ 원클릭 자동 배치` · `📥 붙여넣은 결과 자동 채우기` · `✨ Gemini로 자동 세팅`을 실행하면
① 옛 나레이션 트랙을 먼저 비우고(4초 나레이션이 13초 자막과 따로 놀지 않게),
② `🎙 나레이션까지 자동 생성`이 켜져 있으면 새 자막 **각각과 같은 글·같은 시작 초**로 Gemini TTS를 다시 만듭니다(0초부터 끝까지 1:1).
키가 없거나 이 스위치를 끄면 옛 나레이션만 비우고, 나중에 `🗣 전체 자막 TTS 만들기`로 한 번에 만들 수 있습니다.

## 작업 자동 저장
프로젝트 상태·미디어·커스텀 폰트·커스텀 효과음은 IndexedDB(`reels-studio`)에 저장됩니다.
같은 브라우저에서 다시 열면 이어서 편집할 수 있습니다.

## 기술
- 빌드 도구 없는 정적 사이트 (ES Modules)
- `mp4-muxer` 로컬 번들, WebCodecs `VideoEncoder`/`AudioEncoder`
- 캔버스 2D 합성(1080×1920 좌표계), OfflineAudioContext 믹스다운

## 개인정보
업로드한 파일은 어떤 서버로도 전송되지 않습니다. 모든 처리·합성·인코딩은 클라이언트 사이드에서 이루어집니다.

예외는 두 가지뿐이고, 둘 다 사용자가 직접 켜야 동작합니다.
- **Gemini 자동 세팅·TTS·5채널 캡션**: 프레임 이미지(최대 8장)·자막 문장·블로그 본문이 Google Gemini API로 전송됩니다. 키는 브라우저에만 저장됩니다.
- **블로그 URL 가져오기**: 주소만 무료 텍스트 추출 서비스(r.jina.ai) 또는 공개 프록시로 전달해 본문을 읽어옵니다. 붙여넣기로 쓰면 이 전송도 일어나지 않습니다.
- 프롬프트 복사는 클립보드에만 넣고 아무 데도 보내지 않습니다.
